Zcash merchant checkout

A merchant service built on librustzcash compiled to wasm: mint an address per invoice, watch the chain, attribute payments to orders. It holds a key that cannot spend.

Demo only. This page holds the merchant's viewing key in your browser so it can run with no server. Never do that in production — anyone with that key can read every payment the merchant has ever received. In a real deployment it stays behind the company's own API and the frontend only ever sees invoice status.
